JHORRO PRODUCTIONS - BRAND KIT
==============================

Everything needed to use the Jhorro Productions identity. The rules for using
it (clear space, minimum sizes, colors, don'ts) are in jhorro-brand-guide.pdf.


WHICH FILE DO I NEED?
---------------------

  Website, print, anything that scales ..... the SVG files
  Software that only takes images .......... the PNG files (transparent)
  Website favicon .......................... 02-favicon (see favicon-snippet.html)
  Profile pictures, banners, posts ......... 03-social/<platform>
  Game boot screen, trailer end card ....... 04-splash


FOLDERS
-------

  01-logo/stacked/          Primary logo. svg/ and png/ (1000, 2000, 4000 px wide)
  01-logo/stacked-slogan/   Primary logo with "YOUR ATTENTION IS APPRECIATED."
  01-logo/horizontal/       Symbol left of the name, for wide spaces
  01-logo/wordmark/         Name only, for when the symbol is already nearby
  01-logo/symbol/           The symbol alone. svg/ and png/ (512 to 4096 px)
  01-logo/symbol-tiles/     The symbol on a solid square: dark (red on black),
                            red (black on red), bone (bone on black)
  02-favicon/               favicon.ico, favicon.svg, 16/32/48 px PNGs,
                            Apple and Android icons, site.webmanifest,
                            favicon-snippet.html (paste into <head>)
  03-social/                LinkedIn, YouTube, X, Bluesky, Instagram
  04-splash/                1920x1080, 2560x1440, 3840x2160, Steam Deck 1280x800

Every banner, post and splash screen has a logo-only version and a version
with the slogan (file name ending in -slogan).


COLOR TREATMENTS (in the file names)
------------------------------------

  dark    red symbol and rules, bone text   - for dark backgrounds (house style)
  light   red symbol and rules, ink text    - for light backgrounds
  bone    all bone                          - one color, on dark
  black   all ink                           - one color, on light
  red     all red                           - one color, on light
  white   symbol only, pure white           - video overlays

Profile pictures in 03-social come in the three tile colors: dark, red, bone.
